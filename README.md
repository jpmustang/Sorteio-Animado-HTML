# 🎲 Sorteador de Nomes Online

Um sorteador simples, rápido e direto ao ponto para escolher nomes aleatoriamente a partir de uma lista.

Ideal para:

* Sorteios rápidos
* Dinâmicas de equipe
* Decisões aleatórias
* Brincadeiras entre amigos 😄

---

## 🚀 Acesse o projeto

👉 *https://sorteio-animado-html.vercel.app/*

---

## 🧠 Como funciona

1. Digite os nomes no campo de texto (um por linha)
2. Clique no botão **Sortear**
3. O sistema escolhe aleatoriamente um nome da lista
4. Resultado exibido instantaneamente na tela
